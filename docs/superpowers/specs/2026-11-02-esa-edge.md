# ESA 迁移 Spec

把双人游戏从 GitHub Pages + Supabase 迁移到阿里云 ESA 边缘函数 + 边缘 KV。玩法、页面文案、客户端对局协议（承诺值锁词、消息格式、PT 状态码）不变。

整个应用（网页 + 房间后端）打包成单个边缘函数：`POST /api/room` 走房间协议，其余路径返回内联静态资源，浏览器默认同源。房间数据每个房间一个 JSON 文档存在边缘 KV，账号私有，靠席位令牌鉴权。

Edge KV 无事务无 CAS：并发加入用「读改写回 + writeId 校验 + 冲突重试」乐观锁保证只剩一个客人席位；消息写入被并发覆盖时由客户端轮询回显确认兜底重发。心跳写入 15 秒节流，轮询 1.5 秒。ESA 免费版每天 10 万次函数请求，KV 读写按量计费，需在文档说明。

移除 Supabase/PGlite/`supabase/setup.sql` 及其测试。本地开发服务器用同一份协议的内存存储。发布 = `npm run build:esa` 生成单文件 `dist/esa/worker.js` 粘贴进 ESA 控制台。
